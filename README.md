# 🎰 Animal Slot Game

Высокопроизводительный игровой движок для слот-игр, построенный на **TypeScript** и **PixiJS v8**. Проект спроектирован с упором на максимальную производительность рендеринга и автоматизацию процесса подготовки ресурсов (Asset Pipeline).

## 🚀 Ключевые показатели и оптимизация

*   **Draw Calls: 1 (Static State)** — Весь игровой экран (фон, барабаны, статический интерфейс) отрисовывается за один вызов отрисовки. Достигнуто за счет правильной Z-order структуры и минимизации переключений контекста GPU.
*   **Dynamic Filter Management** — Использование тяжелых фильтров (например, `BlurFilter` для эффекта вращения) полностью автоматизировано. Фильтры активируются только в фазе движения и обнуляются (`filters = null`) в покое, что восстанавливает батчинг и разгружает GPU.
*   **Performance Headroom** — Благодаря оптимизации Scripting-фазы и минимизации Draw Calls, движок сохраняет стабильные 60 FPS даже на устройствах с низким GPU-профилем.

## 🛠 Автоматизированный Asset Pipeline (Node.js & Gulp)

В проект интегрирована профессиональная система подготовки ассетов, заменяющая ручную оптимизацию:

1.  **Native Sharp Compression** — Автоматическая пакетная конвертация `PNG/JPG` -> `WebP` с использованием нативных потоков (Node.js Streams). Это гарантирует минимальный вес билда без потери визуального качества.
2.  **Smart Assets Watcher** — Система в реальном времени отслеживает изменения в папке `src/assets`. При добавлении или удалении исходника, оптимизированный файл в `public/assets` обновляется автоматически.
3.  **Automated Manifest Generation** — Gulp-скрипт динамически сканирует директории и генерирует `manifest.json`. Ресурсы автоматически распределяются по **Asset Bundles** на основе структуры папок.
4.  **Data-Driven Initialization** — Игровые ключи символов (Reels) не захардкожены. Система извлекает их из метаданных загруженных ресурсов, что позволяет менять состав барабанов без правки кода.

## 🏗 Архитектура проекта

### Модульная загрузка (Lazy Loading)
Реализована многоэтапная инициализация через `PIXI.Assets`:
*   **Main Bundle**: Мгновенная загрузка фона и критического UI для исключения "черного экрана".
*   **Reels Bundle**: Асинхронная подгрузка игровых атласов непосредственно перед инициализацией контроллера барабанов.

### Адаптивный Layout
Система ресайза отделена от логики создания объектов. Единый метод `resize` управляет масштабированием и центрированием всех контейнеров, гарантируя корректное отображение на любых разрешениях экрана сразу после завершения асинхронной загрузки бандлов.

## 📦 Команды разработки

Проект использует **pnpm**:

### Установка зависимостей
```bash
pnpm install
```

### Запуск среды разработки (Game Server)
```bash
pnpm dev
```

### Запуск Gulp Watcher для работы с ассетами
```bash
pnpm watch:assets
```

### Сборка ассетов и манифеста
```bash
pnpm build:assets
```

### Полная сборка проекта
```bash
pnpm build
```
